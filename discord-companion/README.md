# Capri's Discord bot

Open **Discord Bot** from the CAPRI section of Windows Mainframe. Set up a Discord application with Server Install, then paste its bot token into the sheet. Node.js 22.12 or newer with npm is required. Capri installs the pinned voice packages on the first connection and saves the token with Windows user protection after Discord accepts it.

Use **Add to server** to install the bot. Join a server voice channel and tell Capri **“Join my Discord call”** through her normal desktop chat. She connects with the saved token when needed and greets you in the call. If the bot can see multiple calls, use **/capri join** in the server you want. **/capri ask** gives the owner a private text reply.

With **Her computer** enabled, the spoken join opens **Capricord**. Its desk icon opens the call window with the channel, avatar circles, and rings that light up as people speak. Use **Wait for name** to quiet Capri, **Talk freely** to let her chime in again, or **Leave** to disconnect her. The owner can also ask her to quiet down or say “Capri, join in again.” The helper posts a notice before it starts listening and leaves when the owner leaves, runs **/capri leave**, or stops the bot in Mainframe.

Capri uses the selected model and voice. The voice channel has its own short conversation history, which clears on leave. Incoming audio stays in memory. Discord uses Capri's installed **Her own ears** speech model independently of the desktop mic, with Windows offline speech available as a fallback. To install the local model, open **Mainframe → Settings → Voice → Speech recognition** and choose **Her own ears**. In open conversation, transcribed speech can go to the selected model provider. In name-only mode, the PC checks for Capri's name before sending a transcript to the model. Voice replies fall back to text in the voice channel when synthesis fails.

The Windows build embeds the helper and its lockfile. The desktop process starts it with private standard I/O pipes. The helper connects directly to Discord and passes text and received audio to Capri. A dependency and codec check is available locally from this folder with `npm ci --ignore-scripts` followed by `node companion.mjs --check`.
