# Arch v0.8.6.1 review candidate

Upstream tag v0.8.6.1: `87d5952305a14dea9defb0e9901b61911fe2c554`, incrementally merged from v0.8.5 `faec52fb6889d6d6b2f2600fa47cab35ca0d4079`. The upstream CROSS payload still says0.8.6; this native adaptation is explicitly0.8.6.1. Keep the public upstream URL, Mochiiwuff attribution, LICENSE.md and THIRD-PARTY-NOTICES.md.

Settings > YOU and the context menu open one file editor for existing personality.md/me.md. Opening creates no note. Save/Ctrl+S is atomic and checks external edits; dirty tabs keep independent drafts. Normal quit waits for recovery. Forced termination cannot guarantee a pending write. Editor file operations run off the UI thread. Decoration policy is scoped to the actual editor window. Native testing of pinned Avalonia11.3.22/X11 found that compositor blur covered the whole window, including the authored transparent header and margins. This candidate disables compositor blur for that exact editor surface and keeps a transparent fallback; panel-region glass blur remains PARTIAL / unavailable through this backend. It uses no screen-copy imitation, global compositor rule or generated art.

Settings > VOICE > Listen for Capri enables actual retained local Moonshine recognition, default off. It discards pre-name text locally and opens20-second follow-ups after the word Capri. This is ASR-based name detection, not a dedicated low-power wake model. Select a physical microphone through TALK first. Stop, mute, sleep, away, lock, account/model/device change or manual TALK closes it; enable it again deliberately. TALK waits for continuous capture to exit. Playback preparation, output and600ms tail bar recognition; physical echo/AEC quality remains unqualified. See NAME_LISTENING.md for assets/offline behavior. No Windows Parakeet/KWS pack replacement is needed for this retained native decoder.

Game sessions resolve the requested app and bind its actual window, continue over bounded fresh90-second/15-action turns, retain bounded history and end on Stop or requested round/win/duration. No uncertain input is replayed. Supported XWayland targets advertise Esc only after the Escape-only observer arms; native Wayland targets retain Stop. Keyboard/mouse focus, process birth, account, permissions, layout, stale frames and pointer takeover remain guarded. Continuous held WASD, gamepad, relative-camera and cross-process game handoffs are unsupported. Automated text entry into XWayland remains blocked because virtual keymaps can send incorrect text. Existing permission-paused screen-job yes/resume behavior is unverified in the normal UI and inherited from baseline.

Voice action recovery is one bounded generation-owned second look only after an action promise with no primary tool. Late original and recovery actions share dispatch authority and cannot both run.

This preview does not replace the normal manual `capri` launcher or enable boot startup. Build/tests, native functionality, physical qualification and owner acceptance are distinct. Chess remains OWNER_REPORTED_FAIL / DEFERRED; preserve its source without claiming the reported incident is solved. Inherited240Hz motion-tail, long-run resource, physical audio/IME/device and human visual gaps remain open unless individually qualified.

Arch font startup explicitly isolates the pinned bundled HarfBuzzSharp native library before GUI use. This prevents system-library symbol interposition from corrupting native font objects; missing package libraries fail clearly. The original MIT loader reference and license are retained under docs/provenance/SkiaSharp. No dependency, font or system configuration change is required.
