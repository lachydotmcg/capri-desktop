# Native interaction fixture

This executable constructs the real `CapriApp` and `Pet`, selects `Desk.Make`, and leaves `Program.Smoke` unset. Run only with a newly created disposable `XDG_CONFIG_HOME` and an absolute private control directory. It rejects a profile containing native account storage. It never belongs in the installed application or an account profile.

Build with `dotnet build tests/native-ui/NativeUi.Tests.csproj`. The single argument is the control directory. Write `request.json` atomically with an integer `id` and a named `command`; consume the matching `response.json`. Commands cover state, composer/hide, public draft/secret fixtures, Mainframe open/close, duplicate-title security sheets, move, local echo/next-prompt sinks, and shutdown. Only the fixture substitutes the request sink; input, draft state, focus, compositor policy and window lifecycle use production code. Public pointer traces contain event kind, local coordinates and owned-window role; they never record keys or prompt contents.

Compile `pointer-driver.c` with `cross/native/virtual-pointer.c`, its include directory and `pkg-config --cflags --libs wayland-client`. It is an explicitly invoked QA injector, not a listener or product service. One persistent virtual device accepts bounded absolute/relative motion and button commands; EOF, signal or the five-minute deadline releases its buttons. Derive dimensions from the observed desktop. Use owned public backdrops, verify every captured workspace, stop recordings on any workspace change, and keep unrelated desktop content out of evidence.

For composer checks require both `composer` and `inputReady` before injecting input. Verify hover then ordinary keys/Escape outside, native Wayland and XWayland outside clicks with unchanged underlying fixture counters, blank versus one accepted submission, ordinary/secret cancellation and callback-opened prompts. Mainframe X must remove the window and keep the pet alive; reopening must produce one window.

Record uninterrupted real-time drags in every present display and both directions across each seam, with reversals and held stops. Bind the source/build, output maps and recorder timestamps. A state trace or decoded still is not human motion approval. Missing physical configurations remain unverified.

`trace-start`/`trace-stop` collect at most100000 in-process pointer/UI/request/ack samples in the disposable fixture. The application installs no recorder. `native-position.c` independently observes ConfigureNotify events on one supplied owned XID; compile with `cc native-position.c -lX11 -o native-position`. Its monotonic records are native position notifications, not physical presentation timestamps. Filter duplicate positions, bound the moving-input interval explicitly, report all measured stages and retain failed intervals.

Menu diagnostics: menu-diagnostic writes bounded public lifecycle/host/row-color and native attribute snapshots. menu-palette-checks checks effective labels across all four looks without applying the diagnostic repair; pass requireSubmenu:true with Size/Move/Help open to qualify submenu template colors. Actual pixel and input checks are required separately.
