# VB-CABLE

`VBCABLE_Driver_Pack45.zip` is VB-CABLE by VB-Audio (Vincent Burel), exactly as VB-Audio publishes it at https://vb-cable.com.
SHA-256 `b950e39f01af1d04ea623c8f6d8eb9b6ea5c477c637295fabf20631c85116bfb`.

- VB-CABLE is donationware. All participations are welcome: https://vb-cable.com
- It isn't Capri's, and Capri's licence doesn't cover it. Its own terms are in `readme.txt` inside the zip and at https://vb-audio.com/Services/licensing.htm. They allow passing the package on as it is, unmodified.
- Capri never installs it on its own. In Settings > VOICE > Her voice in your mic, the Set up button unpacks this zip as it is and opens VB-Audio's own setup. Windows asks the user to let it run, and the user installs the driver in it.

To update it, replace the zip with VB-Audio's newer pack and change `PackHash` in `app/CableSetup.cs` to its SHA-256.
